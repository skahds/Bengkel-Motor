# Bengkelius Motorius

Bengkelius Motorius merupakan usaha bengkel motor yang bergerak di bidang perawatan dan perbaikan kendaraan. Usaha ini menyediakan berbagai layanan, mulai dari servis rutin hingga perbaikan motor, dengan tujuan membantu pelanggan menjaga kondisi dan performa kendaraannya. Website ini dibuat sebagai media informasi untuk memperkenalkan layanan, menampilkan harga servis, serta memberikan informasi mengenai usaha ini.

## Cara Menjalankan Website

1. Clone projek kami dari repository ke dalam komputer.
2. Buka folder projek kami di VS Code.
3. Download extension Live Server di VS Code.
4. Buka file index.html.
5. Klik kanan pada area kosong dalam file tersebut dan cari tulisan "Open with Live Server".
6. Website kami pun terbuka.

## Catatan Proses

1. Navbar sempat mengalami sedikit error. Sempat terjadi kesalahan dalam kodingan. Sekarang sudah aman dan diperbaiki.
2. Pada awal pengerjaan, kami sempat bingung cara kerja sama menggunakan GitHub karena sudah lama tidak melakukannya. Kami berhasil melewatinya dengan melakukan pencarian di internet untuk langkah pengerjaannya.
3. Selama pengerjaan, kami sempat mengalami miskomunikasi sehingga sempat terjadi kesalahan ketika pengerjaan. Kami akhirnya kembali berkomunikasi dan membantu pengerjaan satu sama lain.
